# SafeZone

SafeZone is an emergency-support mobile application created using React Native and Expo.

## Features

- Emergency type selection
- Police, medical, fire, women safety, child protection, accident, and other emergency options
- GPS location access
- Foreground live location updates
- Google Maps location link
- WhatsApp emergency message
- SMS emergency message
- Emergency call button for 112
- Add emergency contacts
- Import contacts from phone
- Delete emergency contacts
- SafeZone logo
- Privacy message

## Technologies

- React Native
- Expo
- JavaScript
- Expo Location
- Expo Contacts
